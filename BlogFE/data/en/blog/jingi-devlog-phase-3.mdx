## Giving players something to do

Beta 0.3.0 adds basic quests and dialogue. Until now, the prototype was mostly about moving and fighting. These systems give players a reason to talk to characters and a task to follow.

<YouTubeEmbed url="https://www.youtube.com/watch?v=mjxqQPazVLI&t=6s" />

## Trying more flexible bot conversations

I also experimented with AI-assisted dialogue so that bots could respond to player questions instead of repeating only fixed lines. The font setup supports English, Japanese, and Vietnamese, with AWS Translate used for translation.

This is still an experiment. Generating a response and displaying it correctly in the game are separate problems, so I do not treat it as support for every language.

## Next steps

The quest and dialogue systems are basic at this stage. My longer-term focus is PvP combat, but I wanted to try these interactions before moving on.
