## Vì sao mình làm ChatGPT++?

Mình viết ChatGPT++ để thử làm một giao diện đơn giản cho OpenAI API. Bản đầu dùng GPT-3.5 Turbo, tập trung vào vài thứ mình muốn nghịch: đọc câu trả lời, thêm ví dụ để hướng dẫn cách phản hồi và lưu hội thoại ngay trong browser.

Trang này mô tả phiên bản đó của dự án. App là một API client với các tính năng riêng, không tương đương với gói thuê bao ChatGPT.

## Những tính năng chính

Browser có thể đọc câu trả lời thành tiếng. Nút “New Teach” cho phép thêm ví dụ để hướng dẫn model trả lời; thao tác này không train lại hay cập nhật weights của model.

Lịch sử hội thoại được lưu trong localStorage trên browser của người dùng, không cần đăng ký tài khoản. Giao diện được làm cho desktop và mobile, còn cải thiện trên tablet là việc để sau.

## Cách dùng giao diện ban đầu

Nhập tin nhắn và bấm Send để nhận câu trả lời. Bạn có thể thêm ví dụ bằng New Teach ở sidebar. Dự án ban đầu cũng cho phép nhập API key của người dùng.

## Chạy thử trên máy

```bash
git clone https://github.com/thangchiba/reactjs-chatgpt.git
cd reactjs-chatgpt
npm install
npm start
```

Dự án cũng có Docker image cho hai kiến trúc:

```bash
# Linux / amd64
docker run -p 3000:3000 thangchiba/chatgpt:amd64

# Apple Silicon / arm64
docker run -p 3000:3000 thangchiba/chatgpt:arm64
```

App local mở ở `http://localhost:3000`.

## Những gì mình học được

Một frontend nhỏ là cách tiện để thử prompting và chat UX. Bản đầu xử lý API access ở client. Nếu deploy cho nhiều người dùng, mình sẽ chuyển phần đó sang backend để private credential không nằm trong frontend bundle.
