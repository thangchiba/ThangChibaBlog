## ChatGPT++を作った理由

OpenAI APIを使うシンプルな画面を試したくて、ChatGPT++を作りました。最初のバージョンではGPT-3.5 Turboを使い、回答の読み上げ、応答例の追加、browser内への会話保存に取り組みました。

このページでは、そのバージョンの内容を紹介しています。独自の機能を持つAPI clientで、ChatGPTのsubscriptionと同じサービスではありません。

## 主な機能

browserの音声機能で回答を読み上げられます。「New Teach」では応答例を追加して、modelの回答を誘導できます。modelのweightsを更新するtrainingではありません。

会話履歴は利用者のbrowserのlocalStorageに保存します。アカウント登録は不要です。desktopとmobile向けに画面を作り、tablet向けの改善は今後の課題としていました。

## 初期の画面の使い方

メッセージを入力し、Sendを押すと回答が表示されます。sidebarのNew Teachから応答例を追加できます。初期のプロジェクトでは、利用者自身のAPI keyを入力する方式も用意していました。

## localで動かす

```bash
git clone https://github.com/thangchiba/reactjs-chatgpt.git
cd reactjs-chatgpt
npm install
npm start
```

2つのarchitecture向けにDocker imageも公開していました。

```bash
# Linux / amd64
docker run -p 3000:3000 thangchiba/chatgpt:amd64

# Apple Silicon / arm64
docker run -p 3000:3000 thangchiba/chatgpt:arm64
```

localでは`http://localhost:3000`で開けます。

## 学んだこと

小さなfrontendでも、promptingやchat UXを試すには十分役立ちました。初期版はclient側でAPI accessを扱っています。複数の利用者に公開するなら、private credentialがfrontend bundleに含まれないよう、backendで扱う構成にしたいと考えています。
